# 2026 연봉 실수령액 계산기

2026년 대한민국 근로소득 기준으로 **연봉(세전) → 월 실수령액**과 **원하는 월 실수령액 → 필요한 연봉**을 계산하는 정적 웹사이트입니다. GitHub Pages 처럼 서버 실행 없이 파일만 올려도 동작합니다. 외부 JS 라이브러리는 쓰지 않습니다.

## 계산하는 것

- 4대보험 근로자 부담분: 국민연금, 건강보험, 장기요양보험, 고용보험
- 근로소득 간이세액표(2026-03-01 시행분) 기준 소득세 원천징수와 지방소득세
- 중소기업 취업자 소득세 감면(청년 90%·5년, 60세 이상·장애인·경력단절 70%·3년, 연 200만원 한도)
- 비과세 항목: 식대, 자가운전보조금, 보육수당, 연구보조비, 취재수당, 벽지수당, 승선수당, 이전지원금, 국외근로
- 생산직 등 연장·야간·휴일근로수당 비과세(연 240만원 한도)
- 일용근로자 일당 원천징수(1일 15만원 공제, 6% 세율, 산출세액 55% 공제, 1,000원 미만 소징수)
- 외국인 단일세율 19%(조특법 §18의2)
- 나이·65세 이후 신규 입사에 따른 국민연금·고용보험 적용 예외
- 국민연금 기준소득월액 상·하한 7월 변경
- 월 세전급여가 최저임금 × 60시간(619,200원) 미만이면 월 60시간 미만 단시간근로로 보고 4대보험 미공제

계산 규칙과 한도는 모두 `data/2026.json` 에서 읽습니다. `js/engine.js` 는 DOM 을 쓰지 않는 순수 ES 모듈이라 `node --test` 로 검증합니다.

## 로컬에서 실행

`fetch('data/...')` 로 데이터를 읽으므로 `file://` 로 바로 열면 동작하지 않습니다. 폴더에서 정적 서버를 띄우세요.

```bash
cd k-salary-net
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

배포 주소는 https://lcalmsky.github.io/k-salary-net/ 입니다. `main` 브랜치 루트를 GitHub Pages 로 그대로 서비스합니다. `js/config.js` 의 `REPO` 는 상단 Star 버튼 링크에, `COUNTER_BADGE` 는 하단 방문자 수 배지(hits.sh)에 쓰입니다. 배지는 `COUNTER_HOST` 에서 열렸을 때만 불러오므로 로컬에서 띄워도 방문 수가 오르지 않습니다.

## 새 연도 데이터로 갱신

1. **간이세액표 파일 추가** — 국세청(홈택스 → 세금신고 → 원천세 신고 → 근로소득 간이세액표)에서 내려받아 `data/simple-tax-2027-01.json` 처럼 저장합니다. 형식은 기존 파일과 같아야 합니다: `rows = [[min, max, 가족1세액, …, 가족11세액], …]`(월 과세대상급여 min ≤ x < max), `at10m = [가족1…가족11 세액]`(정확히 10,000,000원일 때).
2. **연도 파일 추가** — `data/2026.json` 을 복사해 `data/2027.json` 을 만들고, 요율·상한·한도·세율과 `simpleTable.file`(새 표 파일명), `simpleTable.effective` 를 고칩니다. 각 항목의 `source` URL 도 새 근거로 바꿉니다.
3. **연도 선택** — `js/config.js` 의 `DATA_YEAR` 를 `2027` 로 바꿉니다. 앱은 `data/${DATA_YEAR}.json` 을 읽고, 그 안의 `simpleTable.file` 을 다시 읽습니다.
4. **검증** — 새 값을 `tests/engine.test.mjs` 의 기대값(간이세액표 조회, 역산 왕복 등)에 반영하고 `npm test` 를 실행합니다.

## 테스트

```bash
npm test
# 또는
node --test tests/
```

`tests/engine.test.mjs` 는 디스크의 `data/2026.json` 과 간이세액표 JSON 을 직접 읽어 다음을 확인합니다.

- 간이세액표 구간 조회와 1,000만원 초과 구간 공식
- 자녀세액공제 차감
- 중소기업 청년 감면의 연 200만원 한도 소진
- 생산직 연장·야간·휴일근로수당 연 240만원 한도
- 국민연금 7월 상한 변경
- 60세 국민연금 면제, 65세 이후 신규 입사 고용보험 면제
- 실수령액 → 연봉 역산의 왕복 정합성(목표 이상이 되는 최소 월 세전급여)
- 일용근로자 일당 원천징수

## 알려진 한계

- **건강보험 보수월액 상·하한(2026)**: 공식 고시값을 확인하지 못해 상·하한 없이 보수월액 전액에 요율을 적용합니다.
- **국민연금 1~6월 상한 637만/하한 40만**: 공단 1차 자료가 아니라 2차 자료로만 확인했습니다.
- **자녀세액공제 나이 기준**: 2026년 귀속 8세 이상인지 9세 이상인지 1차 조문으로 확정하지 못했습니다. 이 계산기는 간이세액표의 "8~20세 자녀" 입력을 그대로 사용합니다.
- **생산직·중소기업 감면·외국인 단일세율의 요건 판정**: 재직 기간, 업종, 신청 여부 등 계산기에 없는 조건은 사용자가 입력·선택한 값만 반영합니다.
- **일용근로자**: 1개월 미만, 월 8일 미만 근로를 전제로 합니다. 연금·건강보험 적용 여부는 체크박스로 직접 선택합니다.
- **연말정산**: 원천징수 비율(80/100/120%)과 감면은 월 원천징수 기준입니다. 실제 환급·추납액은 연말정산에서 달라집니다.
